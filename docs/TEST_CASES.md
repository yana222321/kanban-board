# Тест-кейсы

Обозначения типов: **U** — модульный, **I** — интеграционный, **E** — E2E, **L** — нагрузочный, **S** — security.

## Ядро (автоматизировано)

| ID    | Название                                            | Тип | Предусловие                         | Шаги                                                                 | Ожидаемый результат                                              | Автотест                                                        |
| ----- | --------------------------------------------------- | --- | ----------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------- | --------------------------------------------------------------- |
| TC-01 | Регистрация нового пользователя                     | I, E | Приложение доступно                 | Открыть `/register`; ввести имя, email, пароль; отправить            | 201, создан пользователь, редирект на «Проекты»                  | `auth.spec.ts` → registers; `integration/auth.test.ts`          |
| TC-02 | Создание карточки на доске                          | I, E | Вход менеджером, проект существует  | Открыть проект; «Добавить карточку» в To Do; ввести заголовок; сохранить | 201, карточка отображается в колонке To Do                       | `board.spec.ts` → creates; `integration/cards.test.ts`          |
| TC-03 | Перемещение карточки между колонками (drag & drop)  | I, E | На доске есть карточка в To Do      | Перетащить карточку в In Progress                                    | Карточка в In Progress, счётчик WIP увеличился (1/3)             | `board.spec.ts` → moves; `integration/cards.test.ts`            |
| TC-04 | Права доступа: разработчик не создаёт проект        | I   | Пользователь с ролью DEVELOPER      | POST `/api/projects`                                                 | 403 Forbidden                                                     | `integration/projects.test.ts`                                  |
| TC-05 | Валидация: пустой заголовок карточки                | I   | Авторизованный пользователь         | POST карточки с пустым `title`                                       | 400 Bad Request с описанием ошибки                               | `integration/cards.test.ts`                                     |
| TC-06 | Поиск карточек по тексту                            | I, E | На доске ≥ 2 карточки               | Ввести текст в поле поиска                                           | Отображаются только карточки, содержащие текст; при несовпадении — пусто | `board.spec.ts` → filters; `integration/cards.test.ts`        |
| TC-07 | WIP-лимит блокирует перемещение                     | I, E | WIP-лимит колонки = 1, колонка заполнена | Перетащить вторую карточку в колонку                             | Перемещение заблокировано, ошибка «WIP limit reached»            | `board.spec.ts` → blocks; `integration/cards.test.ts`           |

| TC-12 | Фильтрация карточек по приоритету     | I   | Выбрать приоритет в фильтре                       | Отображаются карточки только выбранного приоритета    | `integration/cards.test.ts`                           |
